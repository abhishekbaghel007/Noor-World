# 🌻 Noor World

A tiny corner of the internet made of flowers, friends, games, memories and little acts of care.

## Vision
Noor World is designed to feel like a living little world rather than a greeting card. Friends can leave flowers, hugs, notes, jokes, songs and other tiny gifts, and those contributions gradually become part of Noor's garden.

## Stack
Next.js 15 · React 19 · TypeScript · mobile-first CSS

## Planned world
- 🌻 Living garden
- 💌 Send Something
- 🫂 Hugs and customizable flowers
- 😂 Friend jokes and challenges
- 🏆 Noor Awards
- 🧠 Noor Quiz
- 🎵 Shared music
- 📸 Meanwhile snapshots
- 🔒 Open When and secret notes
- 🐻 Tiny pets
- 🎂 Special days
- 🛡️ Moderated private inbox

The first version is intentionally frontend-first. Supabase will be introduced after the interaction model is stable.
